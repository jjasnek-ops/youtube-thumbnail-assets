# Contributing

Contributions are welcome when they improve the reference quality or make the browser utility more useful.

## Good contributions

- Add a source-backed row with the official URL beside the value.
- Add a browser-observed CDN variant only when the test video, date, filename, and natural dimensions are recorded.
- Keep the URL builder dependency-free and client-side.
- Do not add tracking, uploads, login requirements, or undocumented size claims.

## Pull requests

Use one focused change per pull request. Explain the source or reproduction steps in the description, and keep descriptions factual rather than promotional.
