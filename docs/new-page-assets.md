# New page asset notes

## Thumbnail resizer

The live [YouTube Thumbnail Resizer](https://feedthumbnail.com/youtube-thumbnail-resizer) accepts one local PNG, JPG, or WEBP image. Its browser canvas can crop to fill, fit with padding, or stretch to the target frame, then exports a JPG and reports the resulting file size.

The page keeps the upload-limit wording next to the export check and links to the cited YouTube Help source. The asset table records the page as a browser workflow rather than claiming an API or a server-side conversion service.

## End-screen template

The live [YouTube End Screen Template](https://feedthumbnail.com/youtube-end-screen-template) is a still-artwork editor. The headline, supporting line, colors, card labels, and card positions are editable in the local canvas; the export is a PNG still, not a video file.

The page keeps the published YouTube Help rules visible beside the editor. The working canvas is labeled as a page specification when the official Help page does not publish a pixel dimension for an end-screen artwork file.

## Reuse notes

These notes point to the working pages so a reader can verify the behavior directly. No user image, account credential, or private data is included in this repository.
